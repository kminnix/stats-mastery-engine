AP Statistics Formula Sheet: Section II — Inference

General Formula:

$$\text{Confidence Interval: } \quad \text{statistic} \pm (\text{critical value})(\text{standard error})$$ $$\text{Standardized Test Statistic: } \quad \frac{\text{statistic} - \text{parameter}}{\text{standard error}}$$

Single-Sample Inference:

  • Sample Mean (\(\mu\)):
    \(\text{Standard Error: } SE_{\bar{x}} = \frac{s}{\sqrt{n}}\)
    \(\text{Interval: } \bar{x} \pm t^* \left(\frac{s}{\sqrt{n}}\right), \quad df = n - 1\)
  • Sample Proportion (\(p\)):
    \(\text{Standard Error: } SE_{\hat{p}} = \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}\)
    \(\text{Interval: } \hat{p} \pm z^* \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}\)

Two-Sample Inference:

  • Difference of Means (\(\mu_1 - \mu_2\)):
    \(\text{Standard Error: } SE = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}\)
  • Difference of Proportions (\(p_1 - p_2\)):
    \(\text{Standard Error (Intervals): } SE = \sqrt{\frac{\hat{p}_1(1 - \hat{p}_1)}{n_1} + \frac{\hat{p}_2(1 - \hat{p}_2)}{n_2}}\)
    \(\text{Standard Error (Tests - Pooled): } SE_p = \sqrt{\hat{p}_c(1 - \hat{p}_c)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}\)
AP Statistics Formula Sheet: Section I — Descriptive Statistics & Probability

Descriptive Statistics:

$$\bar{x} = \frac{\sum x_i}{n}, \quad s_x = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}$$ $$\hat{y} = a + bx, \quad b = r \left(\frac{s_y}{s_x}\right)$$

Probability & Random Variables:

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$ $$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$ $$\mu_X = E(X) = \sum x_i P(x_i)$$ $$\sigma_X^2 = \sum (x_i - \mu_X)^2 P(x_i)$$

Binomial Distribution (\(X \sim B(n, p)\)):

$$P(X = k) = \binom{n}{k} p^k (1 - p)^{n - k}$$ $$\mu_X = np, \quad \sigma_X = \sqrt{np(1 - p)}$$
