Section I: Descriptive & Probability Formulas

Mean

$$\bar{x} = \frac{\sum x_i}{n}$$

Sample Standard Deviation

$$s_x = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n - 1}}$$

Addition Rule

$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

Conditional Probability

$$P(A \mid B) = \frac{P(A \cap B)}{P(B)}$$

Discrete Random Variables

$$\mu_X = E(X) = \sum x_i P(x_i), \qquad \sigma_X = \sqrt{\sum (x_i - \mu_X)^2 P(x_i)}$$

Binomial Distribution (n trials, probability p)

$$P(X = k) = \binom{n}{k} p^k (1-p)^{n-k}, \qquad \mu_X = np, \qquad \sigma_X = \sqrt{np(1-p)}$$

Geometric Distribution (first success on trial k)

$$P(X = k) = (1-p)^{k-1}p, \qquad \mu_X = \frac{1}{p}, \qquad \sigma_X = \sqrt{\frac{1-p}{p^2}}$$

Sampling Distributions

Sample Proportion: $$\mu_{\hat{p}} = p, \quad \sigma_{\hat{p}} = \sqrt{\frac{p(1-p)}{n}}$$

Sample Mean: $$\mu_{\bar{x}} = \mu, \quad \sigma_{\bar{x}} = \frac{\sigma}{\sqrt{n}}$$

Section II: Inference Formulas

Standardizing Normal Variables

$$z = \frac{x - \mu}{\sigma}$$

Inverse Normal Cutoff

$$x = \mu + z \cdot \sigma$$

Confidence Interval for a Mean (t-Distribution)

$$\bar{x} \pm t^* \cdot \frac{s}{\sqrt{n}}, \quad df = n - 1$$

Confidence Interval for a Proportion (z-Distribution)

$$\hat{p} \pm z^* \cdot \sqrt{\frac{\hat{p}(1 - \hat{p})}{n}}$$

Two-Sample Proportions ($p_1 - p_2$)

Confidence Interval SE: $$SE = \sqrt{\frac{\hat{p}_1(1-\hat{p}_1)}{n_1} + \frac{\hat{p}_2(1-\hat{p}_2)}{n_2}}$$

Hypothesis Test Pooled SE: $$SE_0 = \sqrt{\hat{p}_c(1-\hat{p}_c)\left(\frac{1}{n_1} + \frac{1}{n_2}\right)}, \quad \hat{p}_c = \frac{x_1 + x_2}{n_1 + n_2}$$

Two-Sample Means ($\mu_1 - \mu_2$)

$$SE = \sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}$$

Matched Pairs ($\mu_{\text{diff}}$)

$$SE = \frac{s_{\text{diff}}}{\sqrt{n}}$$

Chi-Square ($\chi^2$) & Linear Regression

$$\chi^2 = \sum \frac{(O - E)^2}{E}, \qquad \hat{y} = a + bx \;\; (\text{or } b_0 + b_1 x), \quad b = r\frac{s_y}{s_x}, \quad a = \bar{y} - b\bar{x}$$
